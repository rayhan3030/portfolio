## Reporting a Vulnerability
If you discover any security vulnerability, unauthorized access concern, or bug regarding this repository or the live website, please report it responsibly directly to the repository maintainer:

- **Maintainer:** Rayhan Ahmed Chowdhury
- **Email:** rayhan3030@gmail.com
- **Response Time:** Security inquiries are typically reviewed within 24–48 hours.

Please do not open public GitHub issues for security vulnerabilities. Thank you for helping keep this project secure!
